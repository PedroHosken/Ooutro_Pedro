# Ooutro Pedro — Media Kit Web

## O que é

Landing page de mídia kit para o criador de conteúdo **Ooutro Pedro**, construída com React + Vite. O site serve como cartão de visita digital para marcas e parceiros interessados em colaborações.

## Proposta de conteúdo

Pedro é um criador de conteúdo multiplataforma focado em **lifestyle autêntico**: rotina real, esporte (corrida, futebol), curadoria cultural e papo direto — sem personagem e sem superprodução.

**Plataformas ativas:**
- YouTube
- Instagram
- TikTok

**Métricas de referência (março/2026):**
- YouTube: 3.500 visualizações / 9,3h de exibição
- Instagram: 7.523 visualizações / 2.723 contas alcançadas (72% não seguidores)
- TikTok: 8.426 visualizações / 285 curtidas / 42 comentários

## Seções do site

| Seção | Descrição |
|---|---|
| Hero | Apresentação e CTAs principais |
| Sobre | Posicionamento do criador |
| Métricas | Números do último mês |
| Diário de bordo | Temas editoriais (esporte, curadoria, cultura) |
| Mapa de parceria | Proposta de valor para marcas |
| Vídeo de apresentação | Embed YouTube |
| Curadoria do Mestre | Playlist recomendada |
| Contato | E-mail, Instagram, TikTok, YouTube, Linktree |

## Stack técnica

- **Framework:** React 19
- **Bundler:** Vite 8
- **Estilo:** CSS puro (`App.css` / `index.css`)
- **Deploy:** Build estático via `vite build` (saída em `/dist`)

## Comandos

```bash
npm run dev      # servidor de desenvolvimento
npm run build    # gera build de produção em /dist
npm run preview  # pré-visualiza o build local
```
